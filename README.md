# Velocity Performance Test Plugin

一個用於 Velocity Proxy 的性能測試插件，可以檢測主機規格、網路速度以及後端伺服器狀態。

## 功能特點

- ✅ **主機規格檢測** - CPU 核心數、記憶體使用率、作業系統資訊
- ✅ **網路速度測試** - 下載速度測試、延遲檢測
- ✅ **後端伺服器狀態** - 顯示所有後端伺服器的線上狀態和玩家數量
- ✅ **完整報告** - 一鍵查看所有性能資訊

## 系統需求

- Velocity 3.3.0 或更高版本
- Java 17 或更高版本

## 安裝方式

### 使用 Maven 編譯

```bash
mvn clean package
```

編譯後的 JAR 檔案會在 `target/` 資料夾中。

### 安裝到 Velocity

將編譯好的 JAR 檔案放入 Velocity 伺服器的 `plugins/` 資料夾，然後重啟伺服器。

## 使用方法

### 指令列表

| 指令 | 說明 |
|------|------|
| `/vperf specs` | 顯示 Proxy 主機規格 |
| `/vperf network` | 測試網路速度 |
| `/vperf servers` | 顯示後端伺服器狀態 |
| `/vperf all` | 執行完整測試 |

### 權限設定

```
velocityperf.use - 允許使用所有 /vperf 指令
```

在 `velocity.toml` 中配置權限，或使用權限插件（如 LuckPerms）管理。

## 使用範例

### 檢查主機規格
```
/vperf specs
```

顯示資訊：
- CPU 核心數
- 記憶體使用情況
- 作業系統版本
- Java 版本
- 目前線上玩家數

### 測試網路速度
```
/vperf network
```

測試項目：
- 玩家延遲 (Ping)
- 下載速度 (Mbps)
- 連線延遲

### 檢查後端伺服器
```
/vperf servers
```

顯示資訊：
- 伺服器名稱
- 線上/離線狀態
- 玩家數量
- 伺服器版本

### 完整測試
```
/vperf all
```

執行所有測試並顯示完整報告。

## 注意事項

⚠️ **網速測試會消耗頻寬**
網速測試會下載 10MB 的測試檔案，建議：
- 不要頻繁執行
- 建議設定冷卻時間
- 僅授權給管理員使用


### 適用場景
- 監控 Proxy 伺服器性能
- 診斷網路問題
- 檢查後端伺服器狀態
- 向玩家展示伺服器規格

### 非同步處理
網速測試和伺服器狀態檢查都使用非同步執行，確保不會影響 Proxy 的正常運作。
